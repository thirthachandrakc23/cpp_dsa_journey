# Time Complexity Notes

## Definition
Time Complexity is the rate at which the execution time grows as the input size (N) increases.

## Big O Notation
Represents the upper bound (Worst Case).

## Rules

1. Always consider Worst Case.
2. Ignore Constants.
3. Ignore Lower Order Terms.

Examples

O(3N) -> O(N)

O(N² + N) -> O(N²)

O(N³ + N² + N) -> O(N³)

## Common Complexities

O(1)

O(N)

O(N²)

O(N³)

## Space Complexity

### Definition

Space Complexity is the total amount of memory used by an algorithm during execution.

### Formula

Total Space = Input Space + Auxiliary Space

### Input Space

Memory required to store the input given by the user.
